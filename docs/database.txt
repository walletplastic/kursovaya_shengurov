В базе данных предусматриваются две основные таблицы: users и orders.

Таблица users предназначена для хранения данных всех зарегистрированных пользователей системы, включая клиентов, сотрудников и администратора. Таблица содержит следующие поля:

id — уникальный идентификатор пользователя;
full_name — ФИО пользователя;
phone — номер телефона;
password_hash — хеш пароля пользователя;
role — роль пользователя в системе.

Для роли пользователя предусматриваются значения: клиент, сотрудник и администратор. Незарегистрированные пользователи (гости) в базе данных не хранятся.

Таблица orders предназначена для хранения заказов на бурение. Для каждого заказа сохраняются:

id — уникальный идентификатор заказа;
client_id — идентификатор клиента, оформившего заказ;
latitude — широта точки бурения;
longitude — долгота точки бурения;
depth — требуемая глубина бурения;
estimate — рассчитанная стоимость заказа.

Поле client_id связывает заказ с пользователем, который его оформил. Один клиент может иметь несколько заказов.
